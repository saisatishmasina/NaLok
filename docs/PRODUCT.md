# Product scope

## Purpose
NEXUS (Java package NaLok) is a desktop workspace for building projects and learning with context intact.
People should be able to browse, read, take notes and practice recall during a focused session, then resume later.

## First public release
- Projects and project sections: outcomes, descriptions and lifecycle.
- Standalone study sessions, optionally associated with a project or section.
- Start/pause/resume/finish, reliable duration accounting, interrupted-session recovery.
- Independent reusable notes and saved sources.
- Dashboard limited to projects/study: resume, next actions, recent sessions, recorded time.
- Desktop browser with multiple tabs and navigation, workspace restoration.
- Split view for source plus notes/recall.
- Supported article reading and quoted highlights with source backlinks.
- Local PDF reader, then supported EPUB; saved position and annotations.
- Link original files or copy into app-managed storage; locate moved files.
- Supported video playback and timestamped notes.
- Manually authored recall questions, review attempts and due scheduling.
- Pegs as mnemonic anchors, concept associations and navigable graph.
- Search, decisions, manual Git references and feature-completion summaries.
- Installation, backup/export, restore and useful errors.

Do NOT redefine the public release as just CRUD plus saved links. That is an internal milestone.
Universal website/login/DRM compatibility is not promised. Provide an external-open fallback.
Finishing a timed session preserves its workspace for later reuse. An open window is not evidence of work.

## Later optional modules
Finance, Gmail, bank/Kalshi connections, sport simulations, physics labs, habits/tasks and AI assistance.
These must not crowd the focused-study dashboard or become prerequisites for study.
